The machine-readable list is index.json. Each dataset has dataset, schema_version, source (rule IDs and their Original status) and records. Values worked out from other rules sit in a derived block, and derived_from names the rule. Datasets with puzzle answers list them in spoiler_fields.

Sources: Game Facts on GitHub. Names and numbers only; no text, maps, art or code from the original game.
