Map files and locations

These rules describe how the MS-DOS release stores its maps: the two 256 x 256 worlds, the settlement floor files, the location numbers that tie them together, entrance coordinates, and four fixed scene maps. Tile values are logical tile indexes (TILE-0001). Map contents remain user-supplied data and are not reproduced here.

World maps and chunk index

MAP-0001Original: EstablishedRedux: Matches

BRIT.DAT (Britannia) and UNDER.DAT (the Underworld) each describe a 256 x 256 grid with one logical tile byte per position. The grid is divided into 256 chunks of 16 x 16 tiles. Chunks are numbered row by row across the world, and tiles row by row within a chunk:

chunk = (y >> 4) * 16 + (x >> 4)
tile  = (y & 15) * 16 + (x & 15)

UNDER.DAT stores all 256 chunks in chunk order: 65,536 bytes. BRIT.DAT omits the 51 chunks that are entirely deep water and stores the other 205 in ascending chunk order: 52,480 bytes. A 256-byte chunk index gives, for each chunk number, the chunk's record in BRIT.DAT, or FF hex for an omitted chunk. The loader fills an omitted chunk with Deep Water, tile 1. The index is compiled into the program and also stored in DATA.OVL at 3886 hex (OVL-0002). Its present entries ascend from 0 to 204, so reading the present chunks in order is equivalent to following the index.

Both worlds wrap at their edges. Closed dungeon entrances and destroyed shrines are substituted while chunks load; neither file stores those states.

Redux reads the index from DATA.OVL, fills omitted chunks with tile 1, and reads BRIT.DAT in chunk order. This match covers file decoding; the runtime substitutions belong to the dungeon and shrine rules.

Settlement floor files

MAP-0002Original: EstablishedRedux: Matches

TOWNE.DAT, DWELLING.DAT, CASTLE.DAT, and KEEP.DAT are each 16,384 bytes: sixteen floor records of 1,024 bytes. A floor is a 32 x 32 grid of logical tile bytes, stored row by row. Location numbers 1-32 select the file in groups of eight (MAP-0003).

A 32-entry table gives the record of each location's ground floor (level 0). The record loaded is that entry plus the signed level, so a basement (level -1) is the record before the ground floor and upper floors follow it. Floor counts are not stored; they follow from the gap to the next location's entry. The table is compiled into the program and also stored in DATA.OVL at 1E2A hex.

Saved state uses the same numbers, for example the party's current map (SAVE-0004) and a companion's inn (SAVE-0002). The values 41 and 42 hex appear while Return to the View runs; their full meaning is not established.

Redux uses the same numbers for 0-40. It reserves further values for its own modes, such as camping, combat, and the finale; those are Redux identifiers, not original data.

World entrances

MAP-0004Original: EstablishedRedux: Matches

Two 40-byte tables give the world X and Y of every entrance, indexed by location number minus one: entries 0-31 are settlements and 32-39 are dungeons. They are compiled into the program and also stored in DATA.OVL at 1E9A hex (X) and 1EC2 hex (Y). Entering matches the party's coordinates against the tables; the tile at each coordinate is the visible entrance. Leaving places the party back at the same coordinate. For a dungeon, the floor it is left by picks the world: the top floor returns to Britannia and the bottom floor to the Underworld (DNG-0003).

Dungeon entrances are listed with their Words of Power in WORD-0001; entries 32-39 agree with it.

Ararat is the only settlement whose entrance is in the Underworld. Doom's entrance exists only in the Underworld. Each of the other seven dungeons has an entrance at the same coordinate in both worlds.

Redux reads both tables from DATA.OVL.

Fixed scene maps

MAP-0005Original: EstablishedRedux: Unverified

The first 704 bytes of MISCMAPS.DAT hold four fixed scenes of 176 bytes each, ahead of the Return to the View data in INTRO-0004. Each record is 11 rows of 16 bytes. The first 11 bytes of a row are logical tiles and the last five are zero, giving an 11 x 11 scene.

OffsetScene
0Blackthorn's interrogation chamber
176A shrine interior
352The Codex chamber
528The endgame room

Each scene is shown through the combat-screen path, location FF. How Redux presents these scenes has not been compared with this layout.
