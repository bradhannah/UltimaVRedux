DATA.OVL index

DATA.OVL is the original program's initialized data, stored as a separate file. These rules give its conventions and an index of identified regions, so tables can be found. Each region's meaning is defined by the topic named beside it. Names and other text stored in the file are not reproduced here.

File identity and conventions

OVL-0001Original: EstablishedRedux: Matches

The shipped DATA.OVL is 48,464 bytes. It is the main program's initialized data segment, linked into a separate overlay file; the program's uninitialized data is not stored. Copies of DATA.OVL that survive in the original source tree match the shipped file only up to offset 28BE hex, so offsets must be checked against the shipped file.

  • Offsets in these rules are file offsets, in hex.
  • Multibyte values are little-endian.
  • Strings are zero-terminated 8-bit ASCII with no length prefix.
  • Coordinates are unsigned bytes held in separate X and Y tables.
  • Two-dimensional tables are stored row by row.
  • String pointer tables hold 16-bit data-segment offsets. Add 10 hex to a pointer to get its file offset; a zero pointer means no string.

Redux checks the shipped size and reads its tables at these file offsets.
